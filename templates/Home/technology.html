Core Technologies Explained

🐍 Backend Framework

Django

Django is a high-level Python web framework following the MVT pattern. It provides everything needed for a secure, scalable web application out of the box.

In our application, Django handles all server-side routing, data modeling, form processing, and security. The Django ORM lets us interact with the database using clean Python code, while Django's admin interface provides a powerful management back-end.

MVT ArchitectureORMMiddlewareAdmin PanelURL RoutingSignals
🐘 Database System

PostgreSQL

PostgreSQL is a powerful, open-source relational database renowned for reliability, data integrity, and advanced features. It is the data backbone of the entire platform.

We store all family records, relationships, trees, user accounts, activity logs, and invitations in PostgreSQL. ACID compliance ensures no family data is ever lost during complex operations.

ACID CompliantRelational SchemaJSONB SupportIndexes & ViewsForeign Keys
📊 Visualization Engine

D3.js

D3.js (Data-Driven Documents) is the industry-leading JavaScript library for creating dynamic, interactive data visualizations in web browsers using SVG, HTML, and CSS.

Our family tree visualization is built entirely on D3.js — rendering hierarchical layouts with smooth transitions, pan-and-zoom navigation, and interactive node selection. D3's force simulation handles complex relationship graphs gracefully.

SVG RenderingHierarchical LayoutForce SimulationZoom & PanTransitions
🔐 Authentication System

Django Authentication

Django's built-in authentication system provides a battle-tested, comprehensive security layer for all user accounts — security built into the foundation, not bolted on.

Every session is managed with hashed passwords (PBKDF2 with SHA-256), CSRF protection on all forms, secure session cookies, and brute-force protection. Our permission system controls exactly what each family member can see or edit.

PBKDF2 HashingCSRF ProtectionSession ManagementPermission Groups
📤 Export System

ReportLab & python-gedcom

Our dual export system lets you share and archive family history in both human-readable and machine-readable formats.

ReportLab (PDF)

Creates beautifully formatted family reports with genealogical charts, individual biographies, and timelines — ready for printing or digital sharing.

python-gedcom (GEDCOM)

Full import/export compatibility with Ancestry, MyHeritage, FamilySearch, and all major genealogy tools via the GEDCOM 5.5 standard.

PDF GenerationGEDCOM 5.5Chart RenderingCross-Platform
🔍 Search Engine

PostgreSQL Full-Text Search

We harness native full-text search built directly into PostgreSQL — providing fast, accurate search without additional infrastructure or external services.

Using tsvector and tsquery, we tokenize, stem, and index all person records for lightning-fast lookup. Custom ranking configurations prioritize the most relevant results, and fuzzy matching accounts for historical spelling variations in names.

tsvector Indexingtsquery ParsingFuzzy MatchingCustom RankingStemming
